# BACKEND

Para ejecutar el framework: python manage.py runserver

# Carpetas

- **root**: Contiene las configuraciones y ruteo de las páginas.
- **tesis**: Contiene modelos, vistas y logica de las vistas.

# Archivos

- **db.sqlite3**: Base de datos ligera, almacena datos de los modelos utlizados.
- **manage.py**: Archivo para ejecutar framework.
- **requirements.txt**: Librerías necesarias para la compatibilidad con el digo utilizado.
